Contributing to AI Mock Interview 🤝

Thank you for your interest in improving AI Mock Interview!

We welcome developers, students, designers, and AI enthusiasts to contribute.

How Can You Contribute?

You can help us by:

- Fixing bugs and errors.
- Improving website design and user experience.
- Adding new interview features.
- Improving AI responses.
- Improving voice interaction.
- Suggesting creative ideas.

How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your improvements.
4. Test your changes.
5. Submit a Pull Request.
6. Wait for the project owner's review.

Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce it.
- Screenshots, if possible.
- Expected behaviour.

Suggesting Features

We welcome new ideas! Open an issue and explain your suggested feature and why it would be useful.

Important Rules

- Be respectful to other contributors.
- Write clean and understandable code.
- Do not upload API keys or passwords.
- Do not submit copied or unauthorised code.
- Test your changes before submitting.

Review Process

All Pull Requests will be reviewed by the project owner.

Changes will be merged only after approval.

Thank you for helping make interview preparation better for everyone!
